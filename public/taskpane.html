    Mail search setup (optional)

    Outlook add-ins can't search the whole mailbox on their own, so search signs in through Microsoft Graph with an app registration you create once (free, about 5 minutes):

    1. Open entra.microsoft.com, then App registrations, then New registration.
    2. Name it anything. For account types choose "any organizational directory and personal Microsoft accounts".
    3. Under Redirect URI choose "Single-page application" and enter https://localhost:3000/auth.html.
    4. After creating it, open API permissions, add Microsoft Graph, Delegated, Mail.Read.
    5. Copy the Application (client) ID into the box below.
